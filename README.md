# Logicification
Logicification is a PCB project that includes NOT, AND, OR, NAND and NOR logic gates. It is small enough that it can work as a large keychain. It included original art from my profile picture, inspired by @acon.

## BOM
- 9 6mm pushbuttons
- 5 5mm LEDs
- 9 220 ohm resistors
- 1 CR2032 Battery and battery holder
- 3 NPN transistors
